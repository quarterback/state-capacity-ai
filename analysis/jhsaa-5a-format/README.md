# JHSAA 5A dual-meet format review

**Question.** Several 5A schools have petitioned to replace the current 1S/4D postseason format
with something more expansive. The association's objection is roster capacity — whether 5A
programs carry enough players to fill a wider lineup.

**Answer: they do, for every format on the table including the association's widest.**

- The association enforces a **hard roster floor of 16**; 4S/5D — nine courts, the widest card
  anyone plays — puts **fourteen** on court. **0.0%** of 445 5A program-seasons fall short of any
  candidate format.
- **55 distinct 5A programs have already played 4S/5D** in showcases — 231 dual-sides, all fourteen
  slots filled every time, including by programs at the sixteen-player floor.
- Every class already running 4S/5D has the same floor-case as 5A (two spare). 5A is thinner in the
  *middle* — median five spare against seven or eight — which is a bench-depth difference, not a
  feasibility one.

**Recommendation:** grant the petition. **4S/5D** for maximum expansion (odd-court, already run by
four other groups); **3S/4D** for expansion with zero new capacity ask. Rule out **4S/4D** and
**3S/5D** — even court counts, tie in ~1 dual in 8, which means adopting a tiebreak regime too.
