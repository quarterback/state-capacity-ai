# Agent-Mediated Public Services Standards

Draft standards for MCP / Agent Experience standards for how to baseline agent experience in the public sector.

## Overview

This repository contains comprehensive standards and guidelines for implementing agent-mediated public services. These standards ensure consistent, accessible, secure, and trustworthy experiences across all public sector digital interactions.

## Website

Visit the public-facing website to explore the full standards documentation:

- **Homepage**: `index.html` - Overview of the initiative and key focus areas
- **About**: `about.html` - Mission, vision, and background information
- **Standards**: `standards.html` - Detailed standards covering 6 core domains:
  - Accessibility Standards
  - Security & Privacy Standards
  - Transparency Standards
  - Interoperability Standards
  - User Experience Standards
  - Compliance & Governance Standards
- **Implementation Guide**: `implementation.html` - Step-by-step implementation instructions
- **Resources**: `resources.html` - Tools, templates, checklists, and code examples
- **Contact**: `contact.html` - Ways to get involved and contribute

## Key Features

✅ **Fully Responsive**: Mobile-first design that works on all devices  
✅ **WCAG 2.1 AA Compliant**: Accessible to all users including those with disabilities  
✅ **Standards-Based**: Built with semantic HTML5 and modern CSS  
✅ **Clean Design**: Professional appearance suitable for government services  
✅ **Comprehensive Navigation**: Consistent navigation across all pages  
✅ **Print-Friendly**: Optimized for printing documentation

## Viewing the Website

To view the website locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx http-server

# Then open http://localhost:8000 in your browser
```
