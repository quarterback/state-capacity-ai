# AI Vendor Requirements (for Public Sector Contracts)

All systems supporting public service decisions must:

1. **Be explainable**
   Provide plain-language reasons for every automated output.

2. **Enable human override**
   Staff must be able to reverse or amend system decisions with documentation.

3. **Maintain a complete audit trail**
   Every automated action must log input data, output, and decision logic.

4. **Support independent testing**
   Provide APIs or exports for third-party accuracy and bias review.

5. **Notify of changes**
   Any model updates or retraining must be disclosed before deployment.

6. **Meet accuracy thresholds**
   Vendors must publish false positive and false negative rates, with contractual penalties for exceeding limits.

7. **Provide recourse pathways**
   End users must have a clear way to request review of automated outcomes.

These clauses can be copied directly into RFPs or interagency agreements.
