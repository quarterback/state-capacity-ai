# AI Enablement Statement

**Service:** Medicaid/CHIP Application Processing
**Agency:** [State] Department of Health Services
**Last Updated:** October 2025

## What This System Does
Automated eligibility determination system that processes MAGI-based Medicaid applications in real-time using electronic data verification.

## AI's Role
- **Assistive (70% of applications):** System automatically verifies income, residency, and household composition using state and federal databases. If all criteria can be verified electronically, system generates approval within 24 hours.
- **Flagging (30% of applications):** System identifies applications requiring manual review due to: data mismatches, missing documentation, or complex household situations.

## Human Decision Authority
- All flagged applications reviewed by eligibility worker within 5 business days
- Workers can override system recommendations with documented rationale
- Complex cases (disability determinations, immigration status questions) always require human determination

## How to Challenge a Decision
- Request manual review: Call [number] or submit form at [URL]
- All denials include specific reason codes and documentation requirements
- Appeals must be filed within 30 days; system-generated decisions use same appeal process as manual determinations

## System Oversight
- Weekly audits of auto-approved applications (random 2% sample reviewed by QA team)
- Monthly error rate reporting published at [URL]
- Bias testing conducted quarterly across demographic groups
- Contact for system errors or concerns: [email]

## System Limitations
This system cannot:
- Make disability determinations
- Assess special circumstance exemptions
- Override federal verification requirements
- Process non-MAGI eligibility pathways (elderly/disabled populations)

## Data Sources
- Social Security Administration (income verification)
- State Department of Revenue (tax records)
- [State] Employment Security Department (wage data)
- Citizenship and Immigration Services (immigration status - when provided by applicant)
