# AI Enablement Statement

**Service:** SNAP Payment Error Rate Reduction
**Agency:** [State] Department of Human Services
**Last Updated:** October 2025

## What This System Does
Document verification assistant that helps eligibility workers identify missing or insufficient documentation before federal PERM audits.

## AI's Role
**Pre-Submission Review:** System scans case files for common documentation gaps that cause PERM errors:
- Missing income verification sources
- Undocumented household composition
- Incomplete address verification
- Missing signatures or dates

**Worker Alert:** Generates checklist of potential issues for worker review before case finalization.

## Human Decision Authority
- Workers review all alerts and determine if additional documentation needed
- Workers can mark alerts as "not applicable" with brief explanation
- Workers make final eligibility determination; system only flags potential documentation issues
- No automatic denials or benefits reductions

## How This Affects Applicants
**What changes:** Workers may request additional documentation to ensure your case file is complete
**What doesn't change:** Eligibility criteria, benefit calculations, and determination timelines remain the same
**Your rights:** Same appeal rights apply; you can challenge any documentation request you believe is unnecessary

## System Purpose
Federal law (HR1) penalizes states for payment errors, including cases with insufficient documentation. This system helps workers ensure case files are complete to:
- Protect state funding for SNAP benefits
- Reduce improper denials due to paperwork issues
- Standardize documentation requirements across workers

## System Oversight
- System recommendations reviewed weekly by policy team
- Worker override rates tracked (excessive override requests trigger system adjustment)
- Applicant burden monitored: documentation request volume tracked by case type
- Published quarterly: documentation request rates, case processing times, approval rates

## What We Don't Do
This system does NOT:
- Calculate benefit amounts
- Determine eligibility
- Auto-deny applications
- Share data with immigration enforcement
- Flag applicants for fraud investigation
